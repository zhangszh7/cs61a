# Declarative Programming

- **Declarative Language**
- **Imperative Language**

**SQL**:(sequel)
- Structured Query Language
> SQL is an example of a declarative programming language.
> Statements do not describe computations directly, but instead describe the desired result of some computation.

**Database Management System**

## Table(relation)

A table is a collection of records, and consists of multiple columns.
Each column has a name and a type.

**record**: data value


### Select

`select [column expressions] from [existing table name];`

**clause**:
- `where`: filter, supports `and`, `or`, `not`.
- `order by <[-]column name>`: sorted
